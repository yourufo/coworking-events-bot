# coworking-events-bot

Telegram-бот для группового чата коворкинга: события и дни рождения участников.
Архитектура и сценарии — см. [PROJECT_BRIEF.md](PROJECT_BRIEF.md).
История изменений проекта — [CHANGELOG.md](CHANGELOG.md).

## Запуск

1. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Скопировать `.env.example` в `.env` и вписать токен бота, полученный
   от [@BotFather](https://t.me/BotFather):
   ```
   cp .env.example .env
   ```
3. Запустить бота:
   ```
   python -m bot.main
   ```

При первом запуске автоматически создастся файл БД `data/coworking.db`
со всеми таблицами.

## Доступные команды

- `/start` — приветствие, регистрирует чат и пользователя в БД
- `/add_event` — добавить событие (пошаговый диалог: название → дата →
  время (необязательно) → описание (необязательно) → подтверждение)
- `/all_events` — показать все предстоящие события чата, без ограничения
  по дате (сортировка от ближайшего к дальнему)
- `/next_event` — показать только самое ближайшее предстоящее событие
- `/delete_event` — удалить событие (список кнопками → подтверждение
  с деталями → удаление; необратимо)
- `/cancel` — прервать любой пошаговый диалог, ничего не сохраняя

Остальные команды из сценариев (`/edit_event`, дни рождения,
напоминания, автозакреп) — в разработке, см.
[CHANGELOG.md](CHANGELOG.md) для актуального статуса и
[PROJECT_BRIEF.md](PROJECT_BRIEF.md) для полного списка сценариев.

**Не забыть после добавления бота в чат:** назначить его администратором
и выдать право `can_pin_messages` — иначе автообновление закрепа (появится
на следующих этапах) не будет работать.
